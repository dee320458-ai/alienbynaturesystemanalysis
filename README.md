# AlienByNature — GitHub Pages

Готовая статическая версия сайта. Сервер и база данных не требуются.

## Публикация на GitHub Pages
1. Создайте публичный репозиторий GitHub.
2. Загрузите **все файлы из этой папки** в корень репозитория.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch.
5. Выберите ветку `main` и папку `/ (root)`, нажмите Save.
6. Дождитесь публикации по адресу `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`.

## Важное о профилях
Профиль сравнения выбирается вручную. Сайт не пытается определять расовую или этническую принадлежность по фотографии. Результаты формы лица и цветотипа являются ориентировочными, а не медицинским заключением.

## Пользователи и безопасность
Файл `new_users_100.txt` с новыми логинами и паролями выдаётся отдельно и **не должен загружаться в публичный репозиторий**.
Сайт использует клиентское шифрование содержимого. Это защищает содержимое от обычного просмотра без учётных данных, но не заменяет серверную авторизацию: список обёрток учётных записей и клиентский код доступны при загрузке сайта. Не используйте этот механизм для особо чувствительных данных.
